* Hyprland Keybindings – Complete Reference

  All keybindings use =SUPER= (the Windows key) as the main modifier,
  unless otherwise noted.

* Launching & Closing
  | Key               | Action                              |
  |-------------------+-------------------------------------|
  | Super+Return      | Open terminal (foot)                |
  | Super+D           | App launcher (fuzzel)               |
  | Super+P           | Power‑search (FSearch)              |
  | Super+N           | Network settings (nm‑editor)        |
  | Super+Shift+C     | Close focused window                |
  | Super+Shift+Q     | Logout (wlogout)                    |

* Navigation & Focus
  | Key               | Action                              |
  |-------------------+-------------------------------------|
  | Super+H           | Move focus left                     |
  | Super+L           | Move focus right                    |
  | Super+K           | Cycle to next window                |
  | Super+J           | Cycle to previous window            |
  | Super+B           | Cycle focus among floating windows  |

* Workspaces
  | Key               | Action                              |
  |-------------------+-------------------------------------|
  | Super+1 … 5       | Switch to workspace 1–5             |
  | Super+Shift+1 … 5 | Move window to workspace 1–5       |
  | Super+Shift+4 … 5 | Move window silently to workspace 4–5 |

* Master Layout
  | Key               | Action                              |
  |-------------------+-------------------------------------|
  | Super+M           | Swap focused window into master position |
  | Super+Shift+J     | Swap with next window in stack      |
  | Super+Shift+K     | Swap with previous window in stack  |
  | Super+Shift+R     | Toggle master ↔ dwindle layout      |

* Dwindle Layout (Emacs‑style splitting)
  | Key               | Action                              |
  |-------------------+-------------------------------------|
  | Super+V           | Force next split to be vertical     |
  | Super+Shift+V     | Swap window with vertical neighbor  |
  | Super+Shift+H     | Swap window with horizontal neighbor |

* Window Management
  | Key               | Action                              |
  |-------------------+-------------------------------------|
  | Super+F           | Toggle fullscreen                   |
  | Super+Shift+Space | Toggle floating ↔ tiled             |
  | Super+G           | Toggle pseudo‑tile                  |
  | Super+C           | Center floating window              |

* Resize Windows
  | Key               | Action                              |
  |-------------------+-------------------------------------|
  | Super+Ctrl+H      | Shrink horizontally                 |
  | Super+Ctrl+L      | Grow horizontally                   |
  | Super+Ctrl+K      | Grow vertically                     |
  | Super+Ctrl+J      | Shrink vertically                   |

* Scratchpad
  | Key               | Action                              |
  |-------------------+-------------------------------------|
  | Super+`           | Toggle scratchpad terminal          |
  | Super+Shift+`     | Toggle scratchpad Emacs frame       |

* Scripts
  | Key               | Action                              |
  |-------------------+-------------------------------------|
  | Super+Space       | (unbound – power‑search is Super+P) |
  | Super+T           | Teleport (switch to window by name) |
  | Super+Alt+S       | Spotlight (toggle float + centre)   |

* Clipboard
  | Key               | Action                              |
  |-------------------+-------------------------------------|
  | Super+V           | Clipboard history (cliphist/fuzzel) |

* Hardware Keys
  | Key               | Action                              |
  |-------------------+-------------------------------------|
  | Volume up         | Raise volume                        |
  | Volume down       | Lower volume                        |
  | Mute              | Toggle mute                         |
  | Brightness up     | Increase screen brightness          |
  | Brightness down   | Decrease screen brightness          |
  | Print             | Screenshot (edit with swappy)       |

* Autostart Applications
  | Program           | Started by                                |
  |-------------------+-------------------------------------------|
  | UWSM finalize     | systemd (session manager)                 |
  | D‑Bus env         | systemd                                   |
  | Waybar            | exec‑once (status bar)                    |
  | mako              | exec‑once (notifications)                 |
  | awww              | exec‑once (wallpaper daemon + image)      |
  | nm‑applet         | exec‑once (network tray icon)             |
  | udiskie           | exec‑once (disk automount tray icon)      |
  | polkit‑gnome      | exec‑once (authentication agent)          |
  | wl‑clipboard      | exec‑once (clipboard history watcher)     |
  | hypridle          | exec‑once (idle daemon)                   |
