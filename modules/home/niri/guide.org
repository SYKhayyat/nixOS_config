    Introduction to Niri
    Niri is a scrollable tiling compositor for Wayland. Unlike KDE Plasma, which uses windows that float on top of each other, Niri treats windows as a "Ribbon" that extends infinitely to the right.

This setup is "Riced" to be keyboard-centric, blazing fast, and fully integrated with your Hebrew/English workflow.

    The Environment Switch
    Your system uses a NixOS Specialisation. To move between KDE and Niri, you must trigger the system switch and then change the session at the login screen.

* Welcome to Niri!

  Niri is a scrollable‑tiling Wayland compositor.  This guide explains your
  personal configuration so you can use it efficiently from day one.

* Input

  | Setting          | Value                        | Meaning                                          |
  |------------------+------------------------------+--------------------------------------------------|
  | Keyboard layout  | =us,il=                      | US English and Hebrew; default is US             |
  | Layout toggle    | =Caps Lock=                  | Tap Caps Lock to switch between English ↔ Hebrew |
  | Caps Lock        | Also acts as =Escape=        | Hold Caps Lock for Ctrl, tap for Escape           |
  | Touchpad scroll  | Natural (fingers down → page down) |                                |
  | Tap‑to‑click     | On                           |                                                  |
  | Disable‑while‑typing | On                       |                                                  |

* Cursor

  The mouse cursor is set to a small size (12) via the environment variable
  =XCURSOR_SIZE=12= in your Home Manager session variables.

* Layout Behaviour

  | Setting                         | Value    | Meaning                                                       |
  |---------------------------------+----------+---------------------------------------------------------------|
  | Default column width            | 50%      | New windows open as a half‑width column.                      |
  | Preset widths                   | 33%, 50%, 66% | Cycle with =Super+R=.                                 |
  | Single‑window centering         | Yes      | When only one window is open, it is centred on screen.        |
  | Multi‑window centering          | No       | When multiple columns exist, they fill the screen left‑to‑right. |
  | Never clip focused window       | Yes      | The focused window is always fully visible.                   |

  These settings ensure you never see a partially cut‑off window.

* Window Rules

  | Application                | Behaviour                           |
  |----------------------------+-------------------------------------|
  | nm‑connection‑editor        | Opens as a floating dialog.         |
  | pavucontrol                | Opens floating (volume control).    |
  | Scratchpad (terminal)      | Floating, 80% width.               |

* Workspaces

  Niri uses *vertical* workspaces.  Navigation:
  - =Super+K= / =Super+J= : move focus up/down between workspaces
  - =Super+Shift+K= / =Super+Shift+J= : move the focused window to the workspace above/below

  You cannot move columns left/right to horizontal workspaces – that action
  does not exist in this Niri version.

* Autostart Applications

  The following programs start automatically:
  - Waybar (with 2‑second delay for reliability)
  - awww (wallpaper daemon) → sets your wallpaper
  - nm‑applet (network tray icon, delayed 2s)
  - udiskie (disk automount tray icon)
  - Polkit‑gnome authentication agent
  - Clipboard history watcher (cliphist)

* FAQ

  - *How do I switch to Hebrew?* :: Press Caps Lock. Tap again for English.
  - *How do I type uppercase letters?* :: Use Shift, as usual.
  - *Why is there no “overview”?* :: Niri’s overview (=Super+Tab=) was removed
    from this config because it is experimental in your version.
  - *I opened Firefox and it’s fullscreen!* :: Press =Super+Shift+F= to
    un‑fullscreen it. Close Firefox normally; next time it will open tiled.
  - *Super+Space does nothing!* :: Your power‑search script launches FSearch;
    make sure FSearch is installed (=fsearch=).

* Customisation

  Your Niri config lives in
  =~/nixos-config/modules/home/niri/default.nix=.  After editing, rebuild
  with =nrs= (or =sudo nixos-rebuild switch --flake ~/nixos-config#desktop=)
  and log back into Niri.
